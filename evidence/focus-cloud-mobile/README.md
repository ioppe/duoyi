## 检查结果

| 项目 | 实际观察 |
| --- | --- |
| 标题与次数 | “专注中”与“0 次专注”保持紧凑两行，次数没有被云按钮推到头部区域外。[顶部细节](../screenshots/focus-cloud-mobile/header-detail.png) |
| 云图标 | 在标题文字组右侧，图形清楚、可点击，位于计时圆环上方；底部无常驻同步文字 |
| 圆环与控制区 | 时间、任务、重置/播放/跳过按钮可见，首屏没有互相遮挡。[整体布局](../screenshots/focus-cloud-mobile/phone-layout.png) |
| 点击提示 | 实际点击已同步云图标后，出现“多端专注已同步”；可访问树中从 1 个按钮标签变为按钮＋提示 2 个同文案节点。[提示截图](../screenshots/focus-cloud-mobile/cloud-hint.png) |
| 时长选择 | 默认能看到自由计时、15、25 和部分 30 分钟；实测左滑后显示 30、45、60、90 分钟。右侧部分按钮是横向滚动的可见边界，不是控件溢出。[滑动后](../screenshots/focus-cloud-mobile/duration-options-scrolled.png) |
| 长任务名 | 选择卡片内按单行省略，圆环下方仍可见完整 `SYNC-REMOTE-TASK`，未挤占旁边白噪音控件 |
| 结束状态 | 恢复时长列表位置，验证包仍停留在专注页并显示已同步。[最终页面](../screenshots/focus-cloud-mobile/final-layout.png) |
