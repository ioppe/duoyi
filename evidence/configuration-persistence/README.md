## 已知边界

升级前仅存在旧进程内存的普通会话不能恢复，升级这一次可能需要重新登录。之后签发的会话在未过期、未撤销的条件下可跨容器重建保留；同账号新登录仍轮换旧普通会话。已经被旧客户端删除、且未同步或备份的配置无法凭空恢复；Web 本地偏好继续按 origin 隔离。

本次上线范围为后端和 Web；已安装的旧原生客户端仍需更新到包含此修复的构建，才具备新的本地偏好清理与保存逻辑。网页强制刷新即可取得新构建，无需清除站点数据。
