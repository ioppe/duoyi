# 我的页「时光足迹」入口

入口使用苹果简约风格：中性卡面、20px 圆角与内距、历史时钟图标与明确标题、本周效率分和同期趋势、细分隔线下的三项统计。原 `AppClock` / `ReportEngine` 评分计算段保持一致。

截图来自 Flutter Release 编译的真实共用组件，通过临时预览页挂载现有 Provider 与主题；预览仅提供「我的」标题作为上下文。完整 `MineScreen` 的入口位置、报表跳转和滚动交互由屏幕测试验证。

常规字号下三项统计同行；窄屏及大字体时按真实列宽减列，分数与趋势可上下排列，文字与数值允许自然换行。

## 验证与迁移

[验证摘要](verification-summary.json) 区分原开发工作区的组件验证与最新远程基线上的提交候选检查。原始命令日志保留在会话临时目录，不随源码提交；远程构建结果以相同提交 SHA 的 GitHub Actions 运行及制品为准。

原开发工作区的最终入口 Widget 测试为 15 项通过，静态分析无问题，完整客户端及共用组件预览的 Web Release 构建成功。原工作区的 100 文件扩展检查有 408 项通过、1 项已有日期断言失败；换回原版卡片后同样失败，该日期测试未在本次迁移中修改。

提交候选以远程 `build/macos-dmg` 的 `873106e54d9ac36cf6e0fdf530df57cdb70fd438` 为基线，保留最新版本、图标、AI 与启动同步实现。迁移只增加两个中英文词条并同步生成类，已有翻译值保持不变。[原工作区范围核对](scope-verification.json) 是组件实现阶段的历史记录，不代表候选分支包含其他未提交修改。

Android、iOS、macOS、Linux 与 Web 共用该入口组件，Widget 测试还覆盖 Windows 的平台模拟。原生端尚未逐一实机安装验证。现有自动构建平台为 Android APK、macOS 通用未签名 DMG/ZIP，以及桌面/手机 Web 包；普通构建分支推送只上传 Actions 制品，GitHub Pages 仍仅允许 main，正式 Release 仍仅由版本标签触发。
