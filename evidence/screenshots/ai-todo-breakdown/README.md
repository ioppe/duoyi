# AI任务拆解与自动填写

[实际页面截图](index.html)来自最终Flutter Web构建，使用独立数据库、临时账号及固定结构化回复，未调用真实模型或使用真实密钥。

## 行为

- AI拆解填写三个有序子任务、已有的学习清单和Q1四象限；用户点击“添加任务”后统一保存。
- 明确的未来时分自动开启提醒并填写时间；只有日期或过去的一次性时间不会自动补提醒。
- 手动改过的清单、象限和提醒保留，关闭提醒会清除新旧提醒字段。AI请求期间改变输入、时区或账号连接会丢弃旧结果。
- 日期预览显示应用IANA时区。本次真实浏览器验证使用当前应用`America/New_York`，仍按该时区的后天15:00解释，不按另一时区静默换算。
- ISO带Z/数值偏移的时间先完整解析并转换到应用时区；date-only保持日历日期；跨午夜同分钟顺延、重复任务与预览共用有效草稿。提醒在序列化和重算后保留日期及明确的夏令时重复小时瞬间。
- Web保存提醒配置并明确说明不支持本地系统通知；安装客户端保留通知权限预检。本次未做APK或真机后台通知到达验证。
