# 今日目标区域字号与对齐

## 改动

- 目标空状态不再使用带默认字号及额外缩进的 `ListTile`，改为与今日待办共用的 `_TodaySectionEmptyState`。
- 两个分区共用图标尺寸、文字起点、圆角、边框和内边距：正文 14px，辅助说明 12px，配色与字体家族继承当前主题。
- 没有副标题时，今日分区标题与右侧操作按钮垂直居中。共享标题组件增加可选对齐参数，默认仍保持原先的顶部对齐。
- 已有目标名称最多两行，采用 14px 正文；进度条与 12px 百分比同行，保留目标自身颜色和原有详情入口。
- 今日页底部增加滚动留白，最后的目标卡片可完整移到悬浮加号上方。
- 字体放大测试同时发现今日统计卡和日期徽章原有高度不足，仅按文字增长补足高度，正常字号维持原有尺寸。
- 空状态保留按钮语义；标题“新目标”与空状态整行均能进入目标创建页。

## 验证

新增 4 条有针对性的行为检查，放入现有 `today_mine_smoke_test.dart` 复用应用 provider：

1. 目标与待办空状态文字左边线一致，正文 14px、辅助 12px、图标 20px。
2. 目标标题与右侧操作按钮中心高度一致。
3. 320×844、390×844、1280×900，浅/深主题、1.5 倍文字、空状态/长目标名称均无溢出，并保留两行标题与 42% 进度展示。
4. 标题按钮和空状态整行都打开真实 `GoalEditScreen`，返回后仍可操作。
