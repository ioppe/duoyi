# 首页统一样式验收

本次将首页待办与目标统一为紧凑文字页签和扁平列表：

- 页签按文字宽度靠左排列，使用显式下划线，避免继承主题中的全宽胶囊选中背景。
- 取消列表中的重复大标题，改为待完成或进行中数量摘要；保留全部待办、全部目标和新目标操作。
- 两页共用内容宽度、边距、摘要字号、条目密度、图标触控宽度及分隔线。待办正文不再重复显示分类图标。
- 任务卡片的彩色边框与外层白卡撤下，逾期/即将到期等状态仍保留颜色提示。
- 待办、习惯、专注三张统计卡改为可点击的紧凑摘要，字体放大时自然换行；一言改为可刷新小字。
- 日历开关、任务完成/详情/左滑删除、目标创建和统计入口保留。

[打开实际构建截图集](index.html)。包含 390 × 844 手机、1440 × 900 桌面、默认主题和星穹铁道深色主题。截图来自本地隔离 Web 服务与临时访客数据；生产服务未部署。

- 页面与国际化测试 43 项通过，包含九套主题在 320/1440 宽度、1.5 倍字体下的页签、无嵌套卡片、条目文本对齐检查，以及统计跳转和已有任务操作。
- 99 个静态/布局测试文件：365 项通过，1 项原有失败。失败为 `test/screens/todo_batch_static_test.dart:122` 的缩进字符串断言，无关文件和该守卫均未修改。
- 最终 `flutter analyze --no-pub` 无问题。
- `flutter build web --release --no-pub --no-wasm-dry-run --no-web-resources-cdn` 通过，校验本地服务的 JavaScript 与最终构建一致。
- 9 个修改的 Dart 文件格式检查 0 changed，`git diff --check` 通过。
- 浏览器验证了顶部切页、临时任务和目标创建、主题切换；未发现 JavaScript 错误。
