# 任务草稿与子任务编辑

[实际页面截图](index.html)来自最终Flutter Web发布构建，使用临时数据库、临时账号与固定结构化AI回复，未调用真实模型或使用用户的密钥。

## 六点修改

1. 新建主输入与详情任务名称使用自动增高的多行文本框，长内容换行；子任务和描述也可换行。
2. 新建和详情共用`TodoSubtaskEditor`，可增加、修改、删除、勾选及拖动子任务。新建草稿隐藏完成勾选，保留编辑、增删和排序。
3. 详情按“任务名称 → 子任务 → 任务描述 → 其他设置”排列，子任务不再位于页面末尾。
4. 每项都使用独立稳定ID，文本编辑保留控制器和选择状态；删除和拖动分别具有44px触点。
5. 关闭默认拖动把手，避免它与右侧删除按钮重叠；拖动同步更新页面草稿顺序，保存时统一提交，避免异步provider重载造成回跳。拖动代理不额外添加默认升降阴影。
6. 结构化AI结果增加可选精简名称。首次成功拆解后，完整用户输入原样保留在可编辑描述中，日期与提醒仍从完整描述识别。手动改过的名称、子任务在再次拆解时也不会被覆盖；旧AI回复缺少title仍兼容。

详情的子任务内容、增删、完成勾选和排序与其他字段统一为页面草稿。右上保存时一次写入任务及子任务聚合后的父完成态，保留未保存返回提示；放弃不会污染provider。只读权限、保存期间禁用、空白子任务校验和失败后重试均保留。
