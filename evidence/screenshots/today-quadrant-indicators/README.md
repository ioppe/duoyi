# 四象限语义色与首页标题间距

首页每个任务标题左侧显示8px实心圆点，使用共享的`todoQuadrantColor`映射与`DesignTokens.quadrantQ1`至`quadrantQ4`。待办页四象限及列表、日历的象限标记、统计卡片同步使用这套映射。

| 象限 | 含义 | 配色 |
|---|---|---|
| Q1 | 紧急且重要 | `#E53935` 红 |
| Q2 | 重要不紧急 | `#8E5CC6` 紫 |
| Q3 | 紧急不重要 | `#F6A339` 黄 |
| Q4 | 不紧急不重要 | `#43A047` 绿 |

这是统一的产品语义约定，保留象限名称，不仅依赖颜色。完成状态、清单分类、事件类型继续使用各自的颜色含义。

## 间距修正

此前圆点位于标题左侧12px处，但内容列与左侧完成控件只有2px间隔，视觉上圆点贴近完成按钮。现在首页内容列与控件使用24px的`homeItemLeadingGap`：圆点、任务名、清单标签及子任务整体右移，圆点距控件边界至少12px。目标页签对应间距同步，保留任务/目标标题的横向对齐。原有子任务进度、完成操作和文字层次保持。
