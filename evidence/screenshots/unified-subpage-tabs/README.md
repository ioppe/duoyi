# 统一页面内部子页切换

按用户要求，将页面内部的子页/内容视图切换统一为首页使用的文字短线页签：左对齐、圆体粗体、选中主题色、22px 短线，点击高度至少 44px，文字放大时随内容增高。页签较多或较长时横向滚动。

## 接入范围

- 首页：今日待办 / 目标，保留实际数量、默认待办与创建行为。
- 习惯：今日打卡 / 热度图；宽屏原有的双栏同时展示保持原样。
- 专注：计时 / 记录 / 自习室。
- 纪念日的全部 / 生日 / 纪念日页签。
- 日历：月 / 周 / 日 / 三日 / 年。
- 扩展功能：日历订阅 / 位置提醒 / 语言。
- 管理后台一级页签和服务器 / 用户备份记录页签。
- 待办的四象限 / 列表 / 看板；随手记的全部 / 归档；时间足迹的时间线 / 分类 / 日历 / 趋势。

日期范围、提醒方式和表单字段继续使用选择控件。登录方式等表单选择没有改动。

## 实现

`lib/core/page_tab_style.dart` 提供统一 `appPageTabTheme` 和 `PageTabIndicator`；`HomeTabIndicator` 为兼容别名，共享同一个绘制器。九套主题都使用共享页签主题。

`lib/widgets/app_page_tabs.dart` 的 `AppPageTabs` 包装现有 TabBar，沿用各页 TabController / TabBarView；`AppPageSwitcher<T>` 为原值驱动的内容视图适配同一套样式，并同步外部选中值、选项数变化及控制器释放。移除各屏的胶囊/填充背景、局部字号和选中态覆盖；后台长页签取消固定宽度，随内容展开。

新增 `page_tabs_static_test.dart` 检查页面内容页签统一经过共享组件，规范写入 `AGENTS.md`。既有源码样式断言随组件提取迁移，保留其他布局、按钮前景、国际化、任务和操作行为检查。
