# 启动同步与云同步卡片验收

本次修复让我的页「云同步」卡片支持点击，并在应用首帧后主动刷新后端配置。界面继续复用现有 AppSurfaceCard、主题颜色、NotoSansSC 与 DesignTokens。

## 同步时机

- 每次冷启动先显示本地内容，首帧后立即请求公开 `/api/config`；已保存登录且开启自动同步时，配置就绪后同步个人数据，不再固定等待约 120 秒。
- 登录或切换账号后同步，回到前台时刷新配置并按需同步；本地改动的既有节流队列、远端 SSE 和版本探针继续生效。
- 点击「云同步」卡片先强制刷新配置，再同步一次数据。配置刷新绕过 30 秒成功缓存，在途请求合并，连续点击不重复上传。
- 自动同步关闭时仍可手动执行一次。管理员关闭备份、未登录或同步特性关闭时，不得上传个人数据；访客仅获取公开配置。

## AI 配置提示

「时光足迹」区分尚未获取/获取中、获取失败与明确关闭。获取中显示细加载提示；失败提供原地重试；只有配置成功且 `ai_enabled=false` 时显示管理员开启提示。刷新配置不会清除已有 AI 历史或在途报告任务，也不会自动调用模型。
