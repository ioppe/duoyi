# AI 解读 Markdown 渲染

[实际页面截图](index.html)来自最终 Flutter Web release 构建，使用独立临时 SQLite、测试管理员和固定回复，不含用户数据。截图环境由临时后端返回 [固定 Markdown 原文](review-fixture.md)，没有调用真实模型或使用真实密钥。

## 修改

- 统计报告的“云端个性化解读”和 AI 历史展开正文共用 `AiReviewMarkdown`。
- 使用 `flutter_markdown_plus` 和 `markdown` 解析章节、强调、有序/无序列表、引用、代码及表格，内容可选择；跟随页面外层滚动。
- 所有正文、标题、代码和表格样式显式继承资源圆体700与主题颜色，保持正文14px、标题层级和统一段落间距，支持窄屏、大字体和深色品牌。
- 对模型回复中的 `**文字。 **` 提供行内解析兼容，不改写原始回复；代码块、行内代码和转义标记仍按字面显示。
- 旧的纯文本历史继续可读，历史默认折叠、逐条展开/收起不变，复制仍返回完整原始 Markdown。服务请求、提示词、历史存储、周期口径与后端均未修改。
- 新增依赖的锁文件按项目固定 Flutter3.44.1生成；其SDK锁定的 `intl`、`meta`、测试包及 `vector_math` 同步回到该SDK兼容版本。

## 验证

- 使用 UTF-8模拟响应进入真实统计页；旧版两个页面用例均因原样显示 `###` 失败，新版通过。用例同时覆盖成功生成、打开历史、折叠/展开、历史读取与原文复制。
- 最终48项相关测试全部通过，包括Markdown组件、统计周期和布局、AI服务、历史静态约束、报告导出约束及字体/国际化规范。
- 组件检查覆盖九主题×320/1440px×1/2倍字体的36个组合，并验证表格、代码、引用、可选择正文及带结尾空格的粗体。
- `flutter analyze --no-pub`、Web release构建、所改Dart文件格式检查及`git diff --check`通过。没有重跑完整Flutter套件、后端套件或APK构建。
- 实际Web流程通过本周效率卡进入统计页、生成固定解读、打开AI历史并展开正文；桌面1440×1100、手机390×1100截图已保存，浏览器无脚本错误。
