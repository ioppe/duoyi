# Web 导航与小组件设置验收

- desktop、mobile、responsive Web 统一默认导航为今日、待办、习惯、我的。窄屏底部导航与宽屏侧栏使用同一入口列表。
- Web 不再提供小组件一级导航，也不能通过导航设置或更多应用将其加回一级导航。
- 新入口：我的 → 设置 → 小组件设置。设置页打开完整的小组件样式配置与预览，支持保存紧凑、标准、详细样式；Web 保存提示明确为当前设备保存。
- 旧 Web 默认的五项导航升级为四项；其他自定义导航顺序与选择保留，并用迁移标记避免之后的自定义选择被重复重置。旧小组件默认启动项回退到今日。
- 原生客户端默认导航保持兼容。迁移标记随账号本地数据清理。
