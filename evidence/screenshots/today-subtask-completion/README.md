# 首页直接勾选子任务

今日页的每条子任务现在是可点行：点一下即完成/取消，不需要进入详情页。

## 交互与样式

- 左侧圆形勾选圈（未完成空心、完成实心主题色），160ms 交叉淡入，让状态变化看得见。
- 完成后标题变浅并加删除线；整行（含标题区域）都可点，行高 36px，保证首页信息密度同时容易命中。
- 勾选立即写回 `TodoProvider.updateTodo`（走默认提醒同步，不跳过），失败时提示「子任务更新失败，请重试」。
- 父任务按既有 `autoToggleByChildren` 规则聚合：全部子任务完成即自动完成父任务，反之取消。
- 只读共享空间点击时提示「共享空间只读，不能完成子任务」，不写入。
- 文案走 `I18n.tr`（中英 + ARB），沿用圆体粗体与设计 token。

## 真实构建验证（本机 18655，Flutter Web release）

1. `01-home-subtasks.png`：今日页任务卡内 3 条子任务，带可点勾选圈。
2. `02-subtask-checked.png`：点击第一条后立即勾选、标题划线；本地存储中该子任务 `isCompleted=true`，父任务仍为未完成。
3. 再次点击可取消，存储恢复为全部未完成。
