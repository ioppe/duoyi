# 共享底部弹窗展开与收回

按用户要求保留原有初始高度，在浏览内容时自动展开到可用整页；回到内容顶部后，再次反向拉动才收回初始高度。该行为由 `AppModalSheet` 统一提供，习惯、待办及其他使用共享组件的表单同步生效。

初始高度仍为键盘上方可用空间的 1/2～2/3；展开状态使用安全区内的整页高度，保留桌面最大宽度、单一手柄、底部安全留白及键盘避让。高度切换动画 220ms，拉动阈值为共享令牌 24px。切换时不重建表单状态或更换滚动控制器。

只跟随第一层竖向内容滚动。返回顶部的那次手势不会顺带收回，轻微位移、推荐项横滑、程序定位和惯性滚动也不切换高度。鼠标滚轮遵循 Flutter 的事件分配，内层时间滚轮消费事件时不影响外层弹窗；顶部收回判断使用事件发生前的位置。自带列表展开后填满剩余高度，即使内容已完整显示，也仍接收收回手势。弹性滚动的阈值按手指原始位移计算。
