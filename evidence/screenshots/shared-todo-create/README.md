# 新建待办复用完整添加表单

首页「新建待办」此前走 `QuickCaptureFab._quickTodo` 的一句话对话框，标题为「快速待办」。现将待办页完整添加表单提取为 `lib/widgets/todo_create_sheet.dart` 的 `showTodoCreateSheet`，首页按钮、快捷菜单的待办入口、待办页新增按钮/空状态和象限页回调均调用它。

保留清单类型、四象限、优先级标记、手动提醒、智能日期解析、AI 子任务、共享空间编辑权限、提醒权限预检及保存错误反馈。象限页仍传入初始象限；目标页新建目标、便笺、AI 指令和模板入口维持原流程。此次没有修改通知/原生小组件的深链接契约。

表单使用既有 `showAppModalSheet` / `AppModalSheet`，保持半屏至三分之二屏、键盘上方布局和内部滚动；复用圆体粗体与标准输入框高度。表单的控制器与异步状态由私有 StatefulWidget 管理，关闭后 AI 返回不会更新已销毁状态；保存中防止重复提交。成功结果返回调用页面后显示提示，首页提示条仍避让 FAB。
