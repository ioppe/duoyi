## 验证边界

浏览器使用独立测试账号与固定模型响应，没有调用生产模型。等待提示改善可理解性，没有证明推理速度变快。已完成历史在同一安装/浏览器持久恢复；未完成请求只在应用服务存活时跨页面继续，不承诺关应用或刷新后续跑。退出或切换账号/服务器仍清理私有历史。

复制在组件测试中检查了传给平台的正文；浏览器确认了菜单动作与“已复制”反馈，但浏览器拒绝剪贴板回读权限。首轮夹具的非 AI 启动控制台发现单独记录在浏览器 JSON 中，不能据此宣称整个应用启动控制台无错误。组件截图和 Web 行为不代表本机原生安装、DMG 拖动、签名或公证验证。
