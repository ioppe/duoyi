# 无内部滚动的等高认证卡片

查看 [实际页面](index.html)。本次替换注册卡片内部的纵向滚动区，保留登录与注册两面尺寸一致、480ms双向翻转、主题和圆体风格。

## 布局

- 邮箱或邀请码策略开启时，常规宽度使用“用户名 → 密码/确认密码并排 → 邮箱 → 验证码与发送”的分组；重复的邮箱要求说明合并到标题下方。
- 密码与确认密码的标签空间不足时自动改为纵向，支持窄屏与放大文字；并排时共用一个可见性开关控制两项密码。
- 两面使用相同注册策略计算高度；可选邮箱绑定状态在来回翻转中保留，避免两面的高度不一致。
- 卡片内部没有纵向 `Scrollable`，必填字段与操作完整排下。大字体、英文换行和提示信息按实际文字度量预留高度。屏幕或键盘空间不足时，仅滚动外层整页。
- 默认不使用邮箱的三字段注册、新用户名作为昵称和管理员邮箱策略均保持。
