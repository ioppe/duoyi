# 新建待办提醒日期与 AI 回填

新建表单开启提醒后分别提供日期与时间按钮。AI 或本地解析得到完整有效的未来日期时间时，自动填写并开启提醒；本地只识别到日期时，可采用同一天的 AI 时分补全。完整本地解析仍优先，只有日期或过去时间不自动开启。

手动选择日期/时间或开关提醒后，后续 AI 不覆盖提醒选择。日期选择取消保持原值。完整提醒时刻保存在现有 `reminderAt` 中，与任务 `date`/`dueDate` 独立；无需新增模型、数据库字段或后端接口。明确选择的过去时间、无效 DST 墙上时间会在提醒区提示，不会静默顺延到次日。
