# 任务详情排版与主题统一

## 修改

- 任务名称 16px；描述、分区标题、字段值和日期行采用 14px；辅助文字及芯片 12px。继续继承当前主题的字体家族、常规字重、颜色和卡片皮肤。
- 详情表单在宽屏中居中限宽（外层最多 840px），手机保留统一的 16px 页面边距。
- 描述、附件、象限/优先级、日期/重复/负责人、目标时长、标签和子任务使用统一卡片内边距与分区间距。
- Markdown 工具栏铺满卡片，内部横向滚动。修复原先内容宽度收缩导致分隔线停在卡片中间的问题。
- 描述输入框显式关闭各状态边框与填充，避免 `InputBorder.none` 被主题的 `enabledBorder` / `focusedBorder` 覆盖而产生双层输入框。
- Markdown 正文使用主题 `onSurface`，链接、勾选色使用 `primary`，行内代码底色使用 `surfaceContainerHighest`，适配深色主题。
- 标签输入独立成行，避免与高度不同的芯片错位。
- 修复已有子任务时 `ReorderableListView` 的直接子项 `Builder` 缺少 key 导致的构建断言；key 从内部 ListTile 移到直接子项。

- 描述工具栏实际边线与卡片对齐；输入区没有叠加边框；宽屏限宽与居中。
- 任务描述、附件、优先级、截止日期、重复行采用相同正文字号。
- 全部 9 个 AppBrands 主题，在 320px 窄屏、1.0 / 1.5 倍字体下滚动无溢出，包含长附件名称、长标签和长子任务。
- 深色 Markdown 正文、链接和行内代码按主题着色。
