# 紧凑认证卡片与默认注册

用户确认默认不用邮箱注册。本次移除注册昵称输入，精简为用户名、密码和确认密码，并缩短共享卡片。查看 [实图页](index.html) 和 [同尺寸前后对比](07-login-comparison.png)。

## 页面与流程

- 默认 Web 卡片：手机460px，桌面484px；此前分别为620px/680px。登录与注册保持同一高度与双向翻转。
- 安装客户端为服务器地址保留一个输入行，长策略表单仍能在卡片内滚动，主操作保持可见。
- 默认只用用户名和密码注册；确认密码是前端校验项。初始昵称取用户名，无需注册时另填。
- 邮件未配置时隐藏可选邮箱绑定。邮件可用且未要求验证时由用户选择；管理员已保存的强制邮箱策略继续生效，不在升级时重置。
- 新库 `registration_email_required=false`，移除旧的自动强制开启迁移；公开 `registration_email_available` 只反映发送能力，与邮箱登录开关相互独立。

## 实际构建

截图 `01`–`04` 分别为1440×1000和390×844登录/注册页，默认注册只有三项输入。`05` 为本地新库通过实际表单直接注册后的“我的”，初始昵称是 `compact_verify`；`06` 为从“我的 → 个人资料”修改昵称后的结果，用户名未变。未设置任何邮件服务即可完成上述流程；浏览器无错误。
