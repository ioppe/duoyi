# 表单高度与文字调整

个人资料、登录/注册、密码重置、邮箱绑定及创建访问令牌表单使用 `AppFormFieldTheme`。

- 输入文字由紧凑控件的 12 调整为 16，行高 1.5。
- 标签和辅助说明由 11 调整为 14；浮动标签考虑 Flutter 默认的 0.75 倍缩放。
- 单行输入框最小高度 56，内边距 16。简介保持多行伸展。
- 昵称与用户名表单的卡片内边距、字段间距为 20。
- 验证码旁的操作按钮与输入框对齐，输入框边界和焦点线更清晰。
