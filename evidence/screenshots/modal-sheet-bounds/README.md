# 底部弹窗统一高度与遮罩关闭验证

## 设计要求

- 卡片高度最少为屏幕的 1/2，最多为 2/3，内容超长时内部滚动。
- 点击卡片上方的遮罩关闭弹窗，卡片内部点击不会误关闭。
- 键盘出现时按键盘上方的可用高度计算比例，卡片位于键盘上方。
- 延续单个拖动手柄、卡片贴底及内容底部安全区留白。

## 实现

- `DesignTokens.modalSheetMinHeightFactor` / `modalSheetMaxHeightFactor` 统一设为 `1 / 2` 与 `2 / 3`。
- `AppModalSheet` 外层 `Align` 设置 `heightFactor: 1` / `widthFactor: 1`，路由的点击区域随卡片收缩。原先透明布局占满路由高度，导致上方空白处拦截点击，遮罩无法收到事件。
- 自带滚动区域（`scrollable: false`）的内容用 `Flexible` 接收扣除标题及操作区后的剩余高度，图标网格与日历详情可以继续内部滚动。
- “新建习惯”从独立的 `AppSurfaceCard` / 手写滚动布局迁移至共享 `AppModalSheet`，移除重复手柄与标题。
- 纪念日编辑器取消允许展开至 95% 的额外 `DraggableScrollableSheet`，使用共享卡片高度与键盘避让，保留模态路由的下滑关闭。
- 分享文本导入允许整体滚动，避免原有固定内容高度在更矮卡片中溢出。

## 自动化验证

新增 `test/widgets/app_modal_sheet_layout_test.dart` 共 13 条行为测试：

- 短、长内容分别在 320×720、390×844、1280×800、844×390 中验证实际 Material 卡片高度。
- 长内容能滚到底并点击完成，卡片内点击不关闭，上方遮罩点击关闭。
- 键盘 inset 为 300 时按剩余高度计算，卡片底边停在键盘上方。
- 自带 ListView 的内容受剩余高度约束，底部条目可访问。
- 320px 窄屏与 1.5 倍文字缩放下无溢出。

修改实现前，13 条新测试中 12 条失败，复现高度与遮罩关闭缺陷。修复后全部通过。

在实际页面测试中补充“快捷模板”“新建习惯”“纪念日编辑器”的高度和遮罩关闭用例。习惯用例使用真实指针拖动到保存按钮，纪念日用例覆盖键盘出现后的卡片尺寸。静态守卫原来固定检查 88% 上限与习惯页面直接包裹二级主题，现改为检查新高度 token 与共享卡片中的等效主题覆盖。

最终验证共执行 108 个测试文件（全部 96 个静态守卫文件与 12 个相关页面/组件测试文件）：**405 条通过 / 1 条既有失败**。

唯一失败是 `test/screens/todo_batch_static_test.dart:122` 的“任务列表减少滑动卡顿和重绘面积”，其硬编码缩进与既有 `todo_screen.dart` 不一致。本次未修改该文件或该断言。

`flutter analyze --no-pub`：**No issues found**。

`flutter build web --release --no-pub --no-wasm-dry-run`：**成功**。
