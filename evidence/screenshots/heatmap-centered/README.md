# 习惯热力图居中与自适应宽度

按用户要求，将习惯页累计打卡热度的绘图区设为卡片内容宽度的 80%，并水平居中。比例包含星期标签和图表内边距；标题仍左对齐。网格使用实际绘图区宽度计算正方形格子，取消此模式的 18px 边长上限；图例在网格下方居中。

`DesignTokens.habitHeatmapWidthFactor` 保存比例。`HabitHeatmap.fitToWidth` 为按调用位置启用的布局选项，只有习惯页开启；详情 20 周图和统计 52 周年度图继续使用原有紧凑密度。放大字体下保留最小可读格子尺寸，空间不足时可横向滚动。自适应模式的月份标签保持单行，利用相邻空白标题列显示，避免窄屏竖排。配色、日期范围和打卡数据逻辑未改动。
