# 父任务完成态由子任务决定

## 规则

- **有子任务**：父任务完成态是推导值——`isCompleted = 全部子任务完成`，任何入口都不能把它单独改成已完成；取消任一子任务会重新打开父任务。
- **无子任务**：保留整任务勾选，可直接完成（仍是原来的确认与时长记录流程）。
- 界面：有子任务的卡片左侧不再显示整任务勾选，改为 `已完成/总数` 进度；首页与待办列表一致。
- 批量完成会跳过仍有未完成子任务的任务，并提示「N 个需先完成子任务」；批量恢复不会单独打开有子任务的父任务（需在子任务里取消）。
- 历史数据里「父已完成但子任务未全完成」的会在加载时自动纠正并写回，新建/更新时也保持该不变式。
- `autoToggleByChildren` 不再能绕过规则（字段仍保留以兼容同步数据，但没有 UI 开关）。

4. 再次取消该子任务，进度回到 `0/5`。
