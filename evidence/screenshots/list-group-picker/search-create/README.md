# 清单搜索与新建一体化

收纳选择器现在只保留一个“搜索或新建清单”输入框。输入期间只过滤清单；没有完全同名项时在结果区显示 `新建“名称”`，点击即可创建、选中并收起。去首尾空白、不区分大小写的完全同名项只允许复用。相关已有项仍可直接点选。回车优先选中完全同名项或唯一已有匹配；多个部分匹配时需用户点选；无匹配且有创建权限时回车可创建。空输入不显示创建项，无创建权限时仅可搜索。

重命名、删除仍通过可见“更多”菜单；名称错误和保存错误都紧贴当前字段显示。本轮没有更改清单 registry、后端契约、任务关联或账号隔离规则。
