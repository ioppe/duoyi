# 我的页分类菜单与免费外观

## 用户要求与结果

1. “我的”首页移除“日程日期”分组。课程、万年历、倒数日、纪念日和生日等工具保留在二级“应用与记录 → 实用工具”中。
2. 首页保留个人信息、四项紧凑统计和四个分类入口：**应用与记录、外观、设置、帮助与关于**。不再在首页展开所有功能和设置。
3. 入口正文统一为 14px，辅助文字 12px，昵称及路由标题使用 16px 设计 token；卡片、分隔线和图标间距统一，字体家族与颜色跟随全局主题。统计卡在放大字体时增加高度，避免底部溢出。
4. 用户及管理员界面取消时光币概念，全部合法外观资源直接使用，不再显示余额、价格、锁或兑换按钮。

## 二级导航

| 首页入口 | 二级内容 |
| --- | --- |
| 应用与记录 | 目标、番茄专注、更多应用、时间足迹、报表、日记、随手记、成就及实用日期工具；启用 AI 时提供周回顾 |
| 外观 | 主题、专注背景、头像框、卡片皮肤、小组件外观 |
| 设置 | 个性偏好、应用锁、云同步、共享、扩展、冲突记录、导出、备份恢复、通知记录与通知设置；管理员可见管理入口 |
| 帮助与关于 | 公告、反馈、更新及版本信息 |

二级菜单继续订阅原 provider 状态，不缓存通知数量或更新提示的旧快照。头像预览、资料编辑、登录/退出和全局搜索入口保留。

## 免费资源与兼容

- 9 个应用主题、5 个专注背景、4 个头像框、4 个卡片皮肤及合法小组件样式全部可用，包含液态玻璃。
- 游客及零余额登录用户直接在本地应用，离线时可用；保存成功后更新选择，并沿用备份/云同步字段。
- 两个历史主题 apply API 继续校验资源 ID，但返回 `charged=0`、`ledger_entry=null`；不扣余额，不生成消费流水。归一化及同步出口返回完整资源目录。
- 当前客户端停止因工作、挑战、成就自动发币；服务端注册、建用户及切组不再自动赠币。业务事件、徽章、挑战进度和解锁提示保留。
- 成就与分享移除币余额、币派生等级和币流水；资料页、管理员用户/分组/设置/权限菜单也不再展示币概念。
- 旧权限 `['coins']` 不会因隐藏该选项被升级为 `['*']`，历史币审计和赠币说明在管理界面不再展示。
- SQLite 列、历史余额/账本、旧配置和旧手动管理 API 保留兼容，未删除历史数据，也未强制将历史余额归零。

## 游客重启回归

浏览器实测发现旧未登录启动清理会删掉外观选择。新增明确游客标记，只在外观页成功应用游客选择时写入。启动清理仍移除旧业务缓存，仅在无账号归属、无认证缓存且具有游客标记时恢复外观四个偏好键；登录、切组和退出仍清理该标记与外观。

新增 4 条回归覆盖游客重启保留、账号归属不恢复、认证缓存不恢复和统一清理路径。
