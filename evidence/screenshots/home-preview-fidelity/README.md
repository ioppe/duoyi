# 首页预览还原修正

此次修正针对上一版实现与已批准 HTML 预览之间的差距，保留实际数据与品牌主题行为。

具体原因与修正：

- 默认主题使用 `ColorScheme.light`，未显式设置 `onSurfaceVariant`，Flutter 将其回退为 `onSurface`，导致日期、摘要、统计和一言与正文同色。本次增加首页专用的正文、辅助、弱提示颜色，其他品牌保留其主题色。
- 原来只改成了普通文字页签，没有实现 22px 短指示线与数量。现在接入实际绘制的短指示线、任务和目标数量，并关闭覆盖其上的主题选中色块。
- 统一参照中的 19px 问候、15px 任务名称、11px 辅助信息，补回 28px 顶部留白。任务分类、副标题、细分隔线和中性完成圆圈分别控制。
- 原方形加号替换为实际可用的文字创建按钮：待办页直接新建待办，目标页直接新建目标，长按访问快捷菜单。原模板、笔记、AI 操作保留。
- 专注摘要改为分钟；任务右侧的更多菜单可查看或删除；一言恢复为弱提示小字。
- 主按钮移入首页后，补齐同层 ScaffoldMessenger，使创建成功提示避让按钮。

[打开同尺寸并排对照](index.html)。原预览和实际入口均为 390 × 844，使用相同任务标题及目标数量。目标颜色、进度值来自真实数据，问候跟随应用时间。另保存 320 × 720、1440 × 900 及深色主题截图。系统字体和原生图标笔形与 HTML 仍有小幅差异，不宣称逐像素一致。
