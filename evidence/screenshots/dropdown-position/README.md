# 修复四象限下拉菜单悬空

问题：新建待办的优先级菜单向上展开时，与下拉框相隔约 166px。共享菜单按 `menuMaxHeight=320` 预留位置，但四行实际只有 `4×36+16=160px`；Flutter `showMenu` 的 `maxHeight` 只是上限，不会强制填满，因此短菜单被抬高。

修复：保留 `showMenu`、键盘收起/锚点稳定、安全区和选中回填流程。用相同的行高和内边距计算内容高度，按内容与调用方高度上限中的较小值判断上下展开和定位；显式统一 PopupMenuItem 的行高、菜单及内容 padding。行高随字体缩放增长，长菜单继续限制高度并滚动。上下展开时均保留 6px 间隔。未改动表单字段和其他页面布局。
