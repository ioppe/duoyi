## 已修复的重启缺陷

旧 v1 真机在保存 7/20/3 后快速重启回落到 5/15/4；在冻结的旧源码中新增回归也得到 `Expected 420 / Actual 300`。原全局业务加载延迟 14 秒，专注页提前进入时自动关联自习室，可能在读入配置之前写回默认配置。

修复为：按当前存储代际按需加载计时配置与恢复数据，成功后才显示计时操作和执行自动房间关联；同代际成功加载后复用状态，失败可重试，旧代际不作为新身份就绪依据。全局 `main.dart` 的启动调度未改。v2 的 C05 实际重启已通过，保存与恢复的完整配置均保留在用例结果中。

旧版发现与新版回归分开记录：[v1 缺陷](v1-finding.json)、[源码哈希](source-hashes.json)、[构建与定向检查](build-validation.json)。原实现阶段的 [Flutter/widget 证据](../focus-rest-layout/README.md) 仍保留为独立历史，不能替代本轮实机结果。
