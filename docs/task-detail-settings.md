# 任务详情、自动保存与清单设置

任务详情统一使用四象限表达任务优先级，与新建任务表单一致。旧的“无、低、中、高、紧急”色标选择行移除，避免同页出现两套容易混淆的设置。历史 `TodoPriority` 字段和列表兼容配色保留；修改四象限、清单或其它详情字段不会重置历史优先级值。

## 自动保存

Web、macOS、安卓等客户端共用任务详情编辑逻辑。已有任务的名称、子任务、描述、标签、附件、清单、四象限、截止日、重复、提醒与目标时长在停止修改约 600 毫秒后自动保存到本地，并通过原有云同步队列同步。页面保留当前位置和输入光标，自动保存不会退出详情。

- 返回键、页面返回按钮和右上角勾号均先保存最后一次修改，再返回上一页；正常流程不再询问是否放弃未保存改动。
- 连续输入及写入期间的新修改按顺序保存，后续修改不会被较早的保存回执覆盖。
- 空任务名称或空子任务在输入过程中暂缓保存，离开时提示填写或删除；保存失败保留页面内容，并提供重试。失败或权限收回后返回时保留当前账号、本次会话内的编辑草稿，重开详情后恢复并重新尝试保存；账号数据清理会移除该会话草稿。
- 仅提醒调度字段变化时执行原有提醒预检；本地写入完成后，提醒重调度在后台处理。保存配置不等于通知已实际送达。
- 新建任务仍使用创建表单的“添加任务”动作；未提交的新建表单关闭时不创建实体。

## 修改清单

详情配置卡片新增“清单类型”，复用 `TodoListGroupPicker`：默认显示当前名称，展开后可搜索已有清单；私有任务还可从同一搜索框新建并选中。收起名称采用与新建页一致的 16px Noto Sans SC 正文。

选择内置或历史名称时清除旧自定义 `listGroupId`，自定义清单同时保存名称与 ID；“未分类”同时清空名称和 ID。清单名称与 ID 都纳入自动保存快照，内置名称之间切换同样会持久化。

任务所属清单的变更随任务详情自动保存，快速返回时也会等待最新选择落盘。清单注册表的新建、重命名、删除沿用选择器原有的独立持久化语义。

## 空间与权限

分类入口不承担跨共享空间移动。可选项为内置模板、当前任务空间的自定义清单、当前空间历史任务清单名及当前名称。选择分类保留原 `workspaceId`、负责人和其它任务字段。

- 私有任务可创建私有清单。
- 共享任务可选择当前空间的内置、自定义或历史名称；当前 provider 的新建接口只创建私有清单，因此共享任务不显示新建动作。
- 只读空间禁用清单和四象限编辑；每次写入前重新核对权限。自动保存期间可继续编辑，后续修改排队保存。
- 页面捕获进入时的账号、服务器和账号数据代际，账号切换后旧页面不能继续选择或保存。选择器内部编辑状态也随连接/provider/代际隔离。

数据字段与同步协议保持原状，见 [自定义清单同步契约](cloud-sync-v2-contract.md#自定义清单list_groups--post-apisync)。选择器通用交互见 [清单类型收纳选择器](list-group-picker.md)。
