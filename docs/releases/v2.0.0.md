# v2.0.0

多仪 2.0 统一 Android、macOS 与 Web 的任务、专注和数据体验，带来一致的品牌形象、更顺手的跨端编辑和更完整的专注记录。

## 界面与品牌

- 全平台统一使用红色圆角方块与三块白色几何图形 Logo，浏览器图标和 macOS 图标保留透明外角。
- 统一 Noto Sans SC 字体、控件和页面间距，改善桌面筛选、四象限布局和窄屏显示。
- Android 提供七档文字大小和实时预览，兼顾系统字号；Web 优化中文字体加载，缩短首次打开的等待。
- 改善输入框对齐、键盘收起和弹层避让，减少编辑过程中的遮挡。

## 任务与跨端设置

- 已有任务停止编辑约 600 毫秒后自动保存，返回时保存最后修改，保留继续编辑时的光标位置。
- 保存失败时保留可重试草稿；同一账号会话内重新打开详情可恢复尚未保存的内容。
- 简体中文、English 和“跟随系统”选择支持账号云同步；“跟随系统”在各设备使用各自的系统语言。
- 完善设备偏好持久化、账号与服务器隔离，以及登录后已有数据的恢复体验。

## 专注与平台体验

- macOS 原生专注悬浮窗支持拖动、暂停与继续，跟随应用主题和语言，并改善紧凑模式与跨屏位置处理。
- Android 桌面小组件支持在组件内切换页签、刷新内容和操作专注计时，保留每个组件的独立显示设置。
- 完善专注时的干扰应用选择、待办及子任务关联，并提供系统日历入口。

## 统计与 AI 报告

- AI 统计解读按自然周、月、年及应用时区归档，重新进入页面可查看对应历史结果。
- 报告生成进度跨页面保留，切换周期或账号时保持结果归属，减少重复请求和历史内容混淆。
- 完善统计周期、时区和专注记录汇总的一致性。

## 安装与升级

- Android：`duoyi-v2.0.0.apk` 为通用安装包，`duoyi-v2.0.0-arm64-v8a.apk` 适用于大多数现代手机；另提供 `armeabi-v7a`、`x86_64` 安装包和 AAB。
- macOS：提供兼容 Apple Silicon 与 Intel Mac 的通用 DMG、ZIP 和 `SHA256SUMS-macos.txt`。安装包尚未配置 Developer ID 签名及 Apple 公证，首次打开可能受到系统安全检查限制。
- Web：提供 `duoyi-web-v2.0.0.tar.gz`、`duoyi-web-desktop-v2.0.0.tar.gz`、`duoyi-web-mobile-v2.0.0.tar.gz`，供自行部署。
- Android 沿用原有正式签名，可覆盖安装同一签名的旧版本；正常升级保留已有账号、任务、专注记录与本机设置。
