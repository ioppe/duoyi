# v1.1.47

本版本新增 macOS 原生客户端与随应用主题更新的番茄计时悬浮窗。

## macOS 客户端

- 新增 macOS Flutter 客户端入口，复用现有账号、服务器连接、主题和专注数据。
- 新增可拖动、置顶、记忆位置的番茄计时悬浮窗；关闭面板不会停止计时。
- 面板沿用当前 App 的卡片、主按钮、圆角和 Noto Sans SC 字体，切换主题时同步更新。
- 运行时显示暂停，暂停后显示已暂停与继续；继续会从原剩余时间接着运行。
- 主窗口关闭后保留计时进程，Dock 可恢复，Command+Q 正常退出。

## 安装说明

- macOS 安装包兼容 Apple Silicon 与 Intel Mac，提供 DMG、应用 ZIP 和 `SHA256SUMS-macos.txt`。
- macOS 安装包未配置 Developer ID 签名和 Apple 公证，首次打开可能受到系统安全检查限制。
