版本 `1.1.47+140013`，构建分支 `fix/android-input-settings-device-test`。本次调整字号选择方式及换账号时的重置规则。

## 本次内容

- “我的 → 个性设置 → 显示与行为 → 应用字体大小”打开独立字号页，提供 85%、100%（标准）、115%、130%、145%、160%、175%、190% 八档滑块。
- 页面采用气泡文字实时预览和底部固定刻度条，点击“完成”保存并全局生效，返回取消未保存的预览。
- 已保存字号在杀进程、重启、会话失效和同账号重新登录后保留，只有成功换到另一个账号才恢复标准。服务器不同也视为不同账号，首次升级绑定账号保留原字号。
- 预览保留系统文字缩放，避免重复叠加应用比例；字号与本机账号标记均不进入云端业务同步。
- 延续先前的键盘收起、其他设置持久化、控件布局、Noto Sans SC 和待办日期预览修复。

## 实机复查

1. 安装前在旧版保存小或大字号，覆盖安装后打开应用，确认原字号保持；杀进程重启两次仍保持。
2. 在独立字号页依次试选八个刻度，预览随之变化；点“完成”后检查待办、习惯、专注、设置和弹层。重新打开字号页确认当前刻度一致；直接返回则不保存草稿。
3. 退出后重新登录同一账号，字号仍保持；换到另一个账号后恢复标准，日期格式、触感等其他本机偏好继续按原规则保留。确认旧账号的私有业务数据与凭据仍被清理。
4. 使用 320px 窄屏及系统大字号，选择应用最大档，确认预览可滚动、滑块和完成按钮可操作，返回键可取消。
5. 保存过程中断网不应影响本机字号；如本机写入失败，应显示错误并停留页面。输入后点击空白、切换页签或弹层时，原键盘收起行为继续可用。
