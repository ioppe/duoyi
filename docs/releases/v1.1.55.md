# v1.1.55

发布当前跨端配置同步、任务自动保存和 macOS 打包修复，并将本版本设为本 Fork 的最新正式 Release。

## 配置同步

- 界面语言的简体中文、English 和“跟随系统”选择纳入账号偏好云同步。
- 同一服务器账号在新 Web、macOS 或安卓端登录并完成同步后，自动应用账号语言选择，无需再次手动设置。
- “跟随系统”在各端使用各自的系统语言；没有显式选择时，不上传系统推断出的语言覆盖值。
- 完善本机偏好持久化与云端回写的竞争处理，保留账号与服务器隔离。

## 任务详情自动保存

- 已有任务的名称、子任务、描述、清单及其他详情配置在停止编辑约 600 毫秒后自动保存。
- 返回时先保存最新修改，不再弹“放弃未保存的修改”确认框；保存期间继续编辑也不会丢失最后一次输入或重置光标。
- 本地写入失败时回滚业务内存并保留可重试草稿；本次账号会话内返回再打开详情可恢复草稿。
- 新建任务仍通过“添加任务”提交，不会因关闭新建表单而意外创建任务。

## macOS 与跨端体验

- macOS 提供与主应用同步的原生专注悬浮窗，支持拖动、暂停与继续、主题与语言更新。
- 修复 DMG 打包时 `lipo` 参数顺序错误；保留 arm64 与 x86_64 双架构校验，新增真实 Mach-O 文件回归测试。
- 统一共享界面字体和控件样式，改善键盘收起、偏好保留及本地 AI 配置体验。

## 安装包

- `duoyi-v1.1.55.apk`：通用 Android APK。
- `duoyi-v1.1.55-arm64-v8a.apk`：大多数现代 Android 手机使用。
- `duoyi-v1.1.55-armeabi-v7a.apk`、`duoyi-v1.1.55-x86_64.apk`：对应 ABI 安装包。
- `duoyi-v1.1.55.aab`：Android App Bundle。
- `duoyi-1.1.55-<提交>-macos-universal-unsigned.dmg`、同名 ZIP 及 `SHA256SUMS-macos.txt`：Intel / Apple Silicon 通用 macOS 应用。
- `duoyi-web-v1.1.55.tar.gz`、`duoyi-web-desktop-v1.1.55.tar.gz`、`duoyi-web-mobile-v1.1.55.tar.gz`：用于自行部署的 Web 客户端。

Android 沿用本 Fork 的正式签名。macOS 安装包未配置 Developer ID 签名及 Apple 公证，构建成功不代表通过 Gatekeeper 或完成实机回归。发布 Web 压缩包不会自动部署现有服务器。

## 版本与发布门禁

- `versionName`：`1.1.55`。
- Android `versionCode`：`140021`，高于此前已发布的 `v1.1.54`（`140020`）。
- `pubspec.yaml` 与 `lib/core/app_version.dart` 保持一致。
- 标签 `v1.1.55` 触发共享分析、完整 Flutter 与后端测试；Android、Web 和 macOS 均构建成功后才发布 Release 并标为 Latest。
- 本次保留既有账号与本地数据，不修改后端接口，不覆盖旧版本标签。
