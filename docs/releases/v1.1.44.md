# v1.1.44

将当前界面统一、专注任务关联和兼容性修复作为本 Fork 的正式版本发布。Android 沿用本 Fork 已配置的正式签名，可覆盖升级同一签名的 `1.1.43` 安装包。

## 界面与交互

- 默认一级导航统一为今日、待办、习惯、专注、我的，保留自定义导航设置。
- 统一各页面的字体、间距、页签、加载、空白和错误状态，同时保留品牌配色、背景图和主题文案。
- 新建入口统一在页面右下角并带文字；任务、目标、笔记、日程等创建表单使用共享底部弹层，支持内容滚动、展开收回和键盘避让。
- 统一轻量反馈与页面过渡节奏，支持系统减少动态效果设置，保留原生返回手势。
- Web 待办页采用纵向分区，习惯页使用今日与热度图页签；补齐列表末项对创建按钮的避让空间。
- 只有密码登录时隐藏多余的方式提示；平台不支持系统勿扰时隐藏专注勿扰入口。

## 专注与数据

- 专注计时支持选择待办或子任务，保存关联身份并按报告周期汇总专注记录。
- 保留手动专注名称、白噪音、自习室、严格专注及历史记录的既有操作。
- 完善账号本地数据隔离，避免切换账号后遗留专注任务关联。
- 完善推理模型输出预算、空回复处理及 AI 报告展示，统一客户端与后端的可配置超时。
- 修复万年历详情分页使用本地经过时长计算日期，导致夏令时期间详情偏移一天的问题。

## 安装包

- `duoyi-v1.1.44.apk`：通用 Android 安装包。
- `duoyi-v1.1.44-arm64-v8a.apk`：适用于大多数现代 Android 手机。
- `duoyi-v1.1.44-armeabi-v7a.apk` / `duoyi-v1.1.44-x86_64.apk`：对应 ABI 安装包。
- `duoyi-v1.1.44.aab`：Android App Bundle。
- `duoyi-web-v1.1.44.tar.gz`、桌面与移动 Web 压缩包：用于自行部署 Web 客户端。
