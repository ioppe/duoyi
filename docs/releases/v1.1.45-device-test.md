# v1.1.45 安卓实机测试包

版本 `1.1.45+140011`，用于验证安卓输入、设置和字体调整。构建分支为 `fix/android-input-settings-device-test`，基于已发布的 v1.1.44 代码准备。

## 本次内容

- 点击输入区域外、滚动、切换导航和路由、打开或关闭弹层时统一收起键盘；保留输入框切换、辅助输入按钮和新页面自动聚焦。
- 修复本机设置在重启、会话失效或账号清理后恢复默认；保存同步冲突标记，配置重载等待写入并在并发修改后自动重读。
- 统一设置控件最小高度与内边距，取消尾部操作缩放；窄屏、大字号下操作区自适应换行。
- 全主题使用离线 Noto Sans SC 字体，正文 16、辅助 14、说明 12、页面标题 20；调整认证卡片高度以适配新字阶。
- 包含已验证的待办日期预览界面调整。

并行开发的本机 AI、设备安全存储和本地账号新模式未纳入这个测试分支。后端初始地址继续使用公开部署配置，已安装客户端可保留自己的服务器连接。

## 构建与安装

本分支推送触发既有 GitHub Actions 流程，完整执行配置校验、分析、Flutter 测试和后端测试，再用仓库已有发布密钥生成通用 APK 与 `arm64-v8a`、`armeabi-v7a`、`x86_64` APK。保持签名规则，不使用调试签名替代发布签名。

推荐手机使用 `arm64-v8a` APK，不确定架构时使用通用 APK。安装应选择覆盖升级，以保留现有数据并验证持久化行为。

## 实机复查

1. 在待办创建、登录、个人资料和设置中输入文字，分别点击空白、其他按钮、切换页签和打开弹层，确认键盘及时收起；切换输入框时仍能连续输入。
2. 修改日期格式、时区、触感、默认入口、导航顺序及提醒，关闭并杀掉应用进程，重启两次确认配置保留。
3. 检查设置按钮与排序操作的触控区域；把系统字号调大，确认控件不被缩小、内容可滚动访问。
4. 切换主题，检查中文、数字、输入框、正文、标题及按钮的字体与层级。
5. 确认已有待办、习惯和计时数据仍可访问；账号退出/切换继续隔离业务数据。

页面组件截图见 [输入与设置验证](../../evidence/screenshots/android-input-settings/README.md)。最终安装包、构建提交和 Actions 运行结果以交付记录为准。
