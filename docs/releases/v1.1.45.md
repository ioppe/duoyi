# v1.1.45

本版本通过 GitHub Actions 发布，新增 macOS 原生客户端与主题化番茄计时悬浮窗，并同步生成 macOS DMG 安装包。

## macOS 客户端

- 新增 macOS Flutter 客户端入口，复用现有账号、服务器连接、主题和专注数据。
- 新增可拖动、置顶、记忆位置的番茄计时悬浮窗；关闭面板不会停止计时。
- 面板沿用当前 App 的卡片、主按钮、圆角和 Noto Sans SC 字体，切换主题时同步更新。
- 运行时显示暂停，暂停后显示已暂停与继续；继续会从原剩余时间接着运行。
- 主窗口关闭后保留计时进程，Dock 可恢复，Command+Q 正常退出。

## 构建与安装包

- GitHub Actions 在 macOS runner 上构建通用 `arm64` / `x86_64` 应用。
- 发布产物包含 macOS DMG、应用 ZIP 和 `SHA256SUMS-macos.txt`。
- 本版本安装包为未配置 Developer ID 签名和 Apple 公证的测试包，不代表通过 Gatekeeper 验证。
