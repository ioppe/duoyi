# v1.1.46 安卓实机测试包

版本 `1.1.46+140012`，用于验证应用字号设置，以及上一版已验证的安卓输入、设置持久化、控件布局和全局字体调整。构建分支为 `fix/android-input-settings-device-test`。

## 本次内容

- 在“我的 → 个人设置 → 显示与行为”中新增“应用字体大小”：小（85%）、标准（100%）、大（115%）。
- 应用字号只影响多仪内部文字，不修改 Android 系统字号，也不影响其他应用；实际字号由系统字号与应用档位共同决定。
- 应用字号作为本机 `pref_text_scale` 保留，重启、会话失效和账号清理后继续生效，不进入云端业务数据。
- 延续上一版的键盘收起、设置持久化、设置控件布局、Noto Sans SC 字体和待办日期预览调整。

## 构建与安装

本分支推送触发既有 GitHub Actions 流程，完整执行配置校验、分析、Flutter 测试和后端测试，再用仓库已有发布密钥生成通用 APK 与 `arm64-v8a`、`armeabi-v7a`、`x86_64` APK。保持签名规则，不使用调试签名替代发布签名。

推荐手机使用 `arm64-v8a` APK，不确定架构时使用通用 APK。安装应选择覆盖升级，以保留现有数据并验证字号和其他本机偏好。

## 实机复查

1. 打开“我的 → 个人设置 → 显示与行为”，切换小、标准、大三个档位，确认登录页、主页面、弹层、设置页文字同步变化；菜单中的“字体大小”应准确滚动到字号控件。
2. 在系统字号为默认和 200% 时分别测试应用小、标准、大档位，确认文字可读、设置控件不被压缩、窄屏内容可滚动。
3. 修改应用字号、日期格式、时区、触感、默认入口、导航顺序及提醒，关闭并杀掉应用进程，重启两次确认配置保留。
4. 在待办创建、登录、个人资料和设置中输入文字，点击空白、其他按钮、切换页签和打开弹层，确认键盘及时收起；切换输入框时仍能连续输入。
5. 切换主题，检查中文、数字、输入框、正文、标题及按钮的字体与层级；确认已有待办、习惯和计时数据仍可访问，账号退出/切换继续隔离业务数据。

最终安装包、构建提交和 Actions 运行结果以交付记录为准。
