# v1.1.52 Android 实机测试包

版本：`1.1.52+140018`。本包修正桌面小组件同步、点击入口和 Android logo，覆盖安装使用现有正式签名。

## 本次行为

- App 内变更通过串行队列推送：正常编辑防抖 2200ms，未完成本地数据加载时保留待推内容，inactive/hidden/paused/detached 立即 flush；推送中再编辑补推最后状态，失败等待下一次变化或恢复前台重试。原生刷新返回 0 不再缓存成功签名。
- 只有核心待办、习惯、月历、专注及历史综合实例的底栏四标签在组件内切页。上方 logo、标题、空白、统计、日期和操作入口打开当前对应 App 分页；具体任务行和具体习惯提示打开各自详情，不直接完成、打卡或开始专注。
- 任务 ID 使用已有详情深链并编码；无有效 ID 的行回到 App 分页，习惯聚合摘要不绑定任意习惯。旧后台动作解析、账号/服务器 owner、应用时区、主引擎桥接及重复操作规则继续兼容。
- 系统暂时查不到 `getAppWidgetInfo` 时，只在 `getAppWidgetIds` 核验实例归属后恢复真实宿主，保留当前页和密度；不接受任意未知 ID。
- Android 启动图标、9 个可见独立组件及历史综合组件左上方改用现有 Web `web/icons/Icon-512.png` 同源 logo。保留隐藏的旧标题 TextView，避免 RemoteViews 文字操作类型不匹配。iOS 和 Web 资源不变。

待办显示范围仍为现有“今日任务”筛选与 Top3 排序。历史综合默认页显示聚合统计，查看任务标题需点击底栏“待办”。本次不扩大今日筛选范围、不改变业务数据模型。
