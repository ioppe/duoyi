# 多仪 v0.1.0

多仪是一款将待办管理、习惯养成、专注计时和日程安排整合在一起的效率应用，帮助你安排每天的行动、保持节奏并回顾自己的进展。

## 待办管理

- 按重要性与紧急程度整理四象限任务，也可切换列表和看板查看进度。
- 使用自定义清单、分组和子任务组织工作与生活中的事项。
- 为任务设置日期、重复规则和提醒，持续跟进完成情况。

## 习惯养成

- 设置每日打卡与按周、按月累计完成的习惯目标。
- 查看打卡记录、连续天数、本周完成情况和习惯热力图，支持补记历史打卡。
- 通过完成状态筛选习惯，集中关注当天需要行动的项目。

## 番茄专注

- 设置专注时长、短休与长休，支持开始、暂停、继续及阶段切换。
- 将专注记录关联到待办和子任务，统计每项任务投入的时间。
- 使用白噪音营造专注环境，查看专注历史与时长统计。
- 同一账号在多台设备之间同步专注计时状态。

## 日历与日程

- 通过月、周、日与三日视图安排日程并浏览每天的事项。
- 在日历中集中查看任务与事件，让计划和实际行动相互衔接。

## 数据回顾与 AI 助手

- 查看任务完成情况、习惯表现、专注投入与活动足迹。
- 配置 AI 服务后，可将一句话想法拆解为可执行的任务和子任务。
- 根据周、月、年的统计生成解读与建议，并查看对应的历史报告。

## 个性化体验

- 提供 8 套主题，可切换配色、背景与主题文案。
- 支持中英文切换、跟随系统语言、文字大小调整和应用时区设置。

## 多端使用

- 支持本地保存记录，并通过账号云同步在不同设备上继续使用。
- Android 桌面小组件可查看待办、习惯与专注状态，并进行快捷操作。
- macOS 专注悬浮窗可拖动位置，直接控制专注计时。

## 目标与生活记录

- 管理长期目标，查看行动进度与成就记录。
- 使用笔记、课程表、倒数日、纪念日、生日与万年历，整理日常信息和重要日期。
