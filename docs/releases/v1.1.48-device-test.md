# v1.1.48 安卓实机测试包

版本 `1.1.48+140014`，构建分支 `fix/android-input-settings-device-test`。本次补充分心应用扫描选择和黑名单/白名单模式。

## 本次内容

- 严格专注不再要求手填分心应用包名；点击“分心应用选择”后扫描 Android 手机上可启动的已安装应用，显示应用名和包名，并支持搜索与勾选。
- **黑名单模式**：勾选的应用才会记录为分心应用，旧版包名配置继续兼容。
- **白名单模式**：勾选的应用视为无关应用，剩余未勾选的可启动应用自动作为分心应用，适合应用较多时只选择少数无关应用。
- 选择器采用草稿模式：取消不保存，点击“完成”才写入；扫描失败时白名单不会静默变成全部放行。
- 不申请 `QUERY_ALL_PACKAGES`，原有 UsageStats 使用情况权限、辅助功能拦截和严格专注惩罚记录保持不变。

## 构建与安装

测试分支推送后运行现有 GitHub Actions：配置校验、静态分析、全量 Flutter 与后端测试，然后使用仓库发布密钥生成分架构和通用 Release APK。只产出测试安装包，不发布正式 Release 或部署服务。

普通安卓手机优先使用 `arm64-v8a` APK，不确定架构时使用通用 APK。覆盖安装以保留已有番茄钟配置。

## 实机复查

1. 打开“番茄专注 → 严格专注 → 分心应用选择”，确认应用列表能加载应用名和包名，搜索和勾选可用。
2. 在黑名单模式勾选微信等应用，开启严格专注后打开它，确认记录“打开分心应用”；取消勾选后不再记录。
3. 切换白名单模式，只勾选需要允许的应用，确认其余可启动应用进入分心集合；扫描失败时页面提示且不会全部放行。
4. 分别测试取消、完成、重新打开设置、退出/重启应用；确认配置保留，旧包名配置升级后仍可用。
5. 在未授予 UsageStats 或辅助功能权限时，确认计时不被阻断；权限页返回后状态能刷新。重点验证 HyperOS/MIUI 权限页和辅助功能保活。

自动化检查、最终安装包、构建提交和 Actions 地址以本次交付记录为准；以上 Android 系统权限和前台拦截项目需要真机验证。
