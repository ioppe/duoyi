# 手动回归清单（Task 25）

对齐 `.kiro/specs/app-alignment-overhaul/requirements.md`。在可用真机上按顺序走完以下 14 条，出现偏差在"状态"栏打叉 + 补截图到 Issue。

## 1. 启动、时区、覆盖更新与应用标志
- [ ] 冷启动后在"我的 → 关于"看到当前 IANA 时区信息（可选；至少日志里 `LocalTimezoneResolver.diagnostics` 为空或只有非致命回退）。
- [ ] 断网启动 → 所有 Tab 可用；App 底部不显示"同步失败"红色状态。
- [ ] 旧客户端选择简体中文并完成云同步；在系统为英文的新浏览器、macOS 或安卓端登录同一服务器账号，完成同步后自动显示中文，无需再次调整语言。
- [ ] 将语言改为“跟随系统”并同步后，各客户端采用自己的系统语言；首次启动未选语言不生成手动覆盖值，提醒等独立偏好同步不会覆盖语言。

- [ ] 保存日期/导航/提醒/时区及当前主题，刷新网页或重启客户端两次；退出后重新登录仍保留设备偏好，旧账号待办、通知历史、同步基线和私密集成凭据不残留。
- [ ] 用密码登录后重启/重建同一数据挂载下的后端，未过期会话仍能读取资料和同步；登出/改密/禁用后旧凭据跨重启仍失效；管理员 AI、邮件和注册配置保持原值。
- [ ] Android/macOS/Linux 及具备发布条件的 iOS：先保存非默认的主题、日期、导航、时区和提醒配置，关闭应用后以相同应用身份覆盖更新（不卸载/不清数据），再冷启动两次，确认配置保留；Web 在同 origin 更新静态 release 后执行相同检查。未执行的平台单独标注，不能用 Provider 测试替代实际覆盖安装结果。
- [ ] 运行 `python3 scripts/sync_app_icons.py --check` 和平台 Logo 测试；对照 `docs/branding.md` 中用户确认的红底白色几何标志，检查 Android 普通/自适应入口、macOS Dock/Finder、Linux 桌面、Web favicon/PWA 和登录页。macOS 全部图标尺寸的圆角外透明，在深浅 Dock / Finder 背景上无白色方底或浅色描边；iOS 图标资源保持同源，有发布环境时补真机检查。切换主题后 Logo 不换图或变色，应用身份与用户数据不变。
- [ ] Android 当前为 `2.0.0 / 142023`，旧后端下发同名 `200000` 时显示已是最新版；GitHub 回退与旧安装缓存同样不误报。真实同名更高 build、新语义版本仍提示；旧语义版本即使 build 较大也不触发降级或强更。
- [ ] 点击下载后关闭弹窗、返回桌面，通知栏继续显示真实下载进度；重新进入或进程重建恢复当前任务。未知总大小显示不确定进度，失败/取消后可重试；完成通知可进入安装流程，拒绝通知或未知来源权限均不丢失状态，不在后台自行弹出安装器。
- [ ] 修改昵称后立即返回今日与我的，均显示新昵称；刷新/冷启动仍保留，空白昵称回退账号名，退出或切号不显示上一账号昵称。

- [ ] 切换"健康 / 学习 / 运动 / 情感 / 推荐" 5 个分段，每个都有 ≥ 5 条条目。
- [ ] 点击任一推荐条目 → SnackBar "已添加到目标列表"；返回"目标"页能看到新条目。
- [ ] 新条目打开编辑页 → 8 个折叠模块（基础/重复/调度/跳节假日/专注/提醒/时长/次数）都可展开。
- [ ] 今日和目标管理的新建入口均使用共享弹窗；Web/macOS 居中，原生 Android/iOS 从底部弹出，背景页面保持可见，内部没有重复 AppBar 或第二层卡片。
- [ ] Web/macOS 的新建目标与任务宽度受 720px 与视口约束，短内容自适应，长内容内部滚动；320px、短横屏、2 倍文字和键盘弹出时可达保存按钮。原生手机仍为 1/2 至 2/3 初始高度，展开/收回保留草稿。
- [ ] 目标、笔记、日程、位置提醒、共享空间、自习室、模板及管理员新增表单统一键盘避让、内容滚动和关闭；居中弹窗支持关闭按钮、Escape、遮罩与焦点循环，嵌套选择器返回只关闭当前层；关闭不创建实体，保存后返回原页面，减少动画时无缩放过程。
- [ ] 今日、习惯等页面的主创建按钮在桌面与手机均位于右下角并显示操作文字；今日与习惯按钮的高度、字号、图标、圆角和内边距一致，点击进入对应创建表单，今日长按仍展开快捷菜单。Android 原生待办主页面改用页头“＋”，右下角无重复创建按钮；象限详情保留定向创建。
- [ ] 目标日期选择、共享空间权限及已有实体的编辑、删除流程仍可正常使用。

## 3. 任务交互
- [ ] 新建一个任务 → 详情页编辑标题 → 停止输入约 600 毫秒后已保存，页面仍停留在详情；返回再打开内容一致。
- [ ] 修改标题或子任务后立即按页面／系统返回 → 最新修改先保存再回列表，全程不出现“放弃未保存的修改？”确认框。
- [ ] 连续输入及保存期间继续编辑 → 最后一次内容全部落盘，光标不跳到末尾；右上角勾号仍可立即保存并返回。
- [ ] 本地写入失败时保留文字并显示重试，返回后在本次账号会话内重开详情可恢复草稿；共享空间编辑权限被收回时同样可以返回，权限恢复后重开可继续保存。暂时空标题或空子任务不会自动写入，修正后继续保存。
- [ ] Web、macOS、安卓分别验证子任务勾选、重排、清单切换与快速返回；切换账号后旧页面的待写草稿不能进入新账号。
- [ ] 任务卡片显示：优先级色点、标签胶囊、下次提醒 HH:MM、目标时长 badge。
- [ ] 勾选完成 → 卡片**保留在今日列表**，显示"已完成"绿色徽章 + 删除线。
- [ ] 取消勾选 → 回到普通态，徽章消失。
- [ ] Web 与 macOS 原生待办页的今日提醒与筛选位于上方，四象限 / 列表 / 看板页签和任务内容位于下方；macOS 宽屏与窄屏都不显示右侧筛选栏，切换三种视图仍保持顶部顺序。
- [ ] 自定义视图选中、取消或清空筛选时标题行、筛选区和页签高度与位置一致，快捷筛选与下拉菜单等高；无筛选时清空按钮禁用。
- [ ] Android 原生 320 / 390px 窄屏打开待办页，顶部默认仅显示页签和单行筛选入口，四象限占主体；展开筛选后，今日 / 逾期 / 7天内 / 已完成和象限、优先级、日期、状态、标签、清单仍可选择，匹配数量与清空正确，收起不丢筛选条件。
- [ ] Android 1.5 倍及 2 倍字号下筛选操作可达且无布局溢出；Web 和原生桌面仍沿用各自既有分区。页头“＋”打开原待办表单，批量模式不显示创建入口。
- [ ] Web 冷启动只下载一次轻量 Noto 子集，中文登录页/首页可用后至少 15 秒才在空闲时请求完整字库；拦截完整字体后仍可输入和切换页面，弱网/省流/后台会跳过，详见 `web-font-loading.md`。
- [ ] 新建任务直接选择截止日期、增加/移除具体时间、清除截止期；提交后详情与重新加载的模型一致，不必先建任务再编辑。
- [ ] 自然语言与固定 AI 拆解结果同时更新截止期的可见字段与保存值；只有日期时不编造时刻或开启提醒，没有日期的输入默认无截止期。
- [ ] 等待 AI 前后手动改/清截止期后，迟到结果不覆盖；取消日期选择后仍允许后续自动回填。修改截止期不改任务进入日期和手动提醒，关闭提醒保留截止期。
- [ ] 清除截止时刻后日期仍保留；在纽约等具有夏令时的应用时区选择跳变时不存在的墙上时间，控件下方提示错误并阻止保存，改为有效时刻或纯日期后可保存。

## 4. 子任务 / 顺延
- [ ] 新建任务带 3 个子任务，`autoToggleByChildren = true`（默认）。
- [ ] 依次勾选 3 个子任务 → 父任务自动标为完成。
- [ ] 取消其中一个 → 父任务自动回到未完成。
- [ ] 新建任务设置昨日 dueDate → 下次启动或 resume 时 → `dueDate` 自动顺延到今日同一时刻，`postponeHistory` 增加一条。

## 5. 通知 vs 闹钟
- [ ] 我的 → 通知设置里的「通知健康检查」卡片显示：系统通知权限、精准闹钟权限、通知渠道、测试通知、已调度提醒。
- [ ] HyperOS / MIUI 设备显示自启动、后台与电池、锁屏与横幅、渠道声音四类人工检查项；这些检查项不出现重复的「去设置」按钮，只保留一个疑难设置入口。
- [ ] 从系统设置返回后，卡片状态刷新，提醒详情里的健康提示同步更新。
- [ ] 任务详情页：提醒开关 = ON，kind = **推送**，时间 = 1 分钟后 → 到点系统通知中心出现，不全屏。
- [ ] 切换 kind = **闹钟**，时间 = 1 分钟后 → 到点**全屏 intent 弹出 + 震动**。
- [ ] Android 12+：第一次选闹钟弹"请开启精准闹钟权限"引导（`AlarmPermissionDeniedException` 被捕获时）。
- [ ] Web 通过 HTTPS 或 localhost 打开任务详情，点击「通知授权」触发浏览器权限请求；允许后状态更新，拒绝、关闭、不支持或非安全上下文均有明确反馈，不再无响应或自动反复弹框。
- [ ] 浏览器已拒绝时按提示从地址栏站点设置允许，再返回网页，提醒健康读取真实状态；连续点击在途授权不重复请求，初始化和自动检查不弹授权框。
- [ ] Web 已授权时即时通知及保持网页打开的定时通知可测试，取消或切换账号后旧通知不再触发；页面明确提示后台节流可能延迟、关闭网页不能保证定时提醒，不把 Web 授权等同于原生精准闹钟。

## 6. 专注模式白噪音
- [ ] 桌面侧栏与手机底栏默认显示「今日 / 习惯 / 专注 / 我的」，导航设置不再列待办，点击专注直接展示计时页并高亮入口。
- [ ] 旧可见/排序集合包含待办时自动过滤，旧默认页为待办时回落今日；其余自定义组合与排序保留，隐藏专注并重启不会重新添加。今日/日历任务入口和旧通知、小组件任务深链仍可用。
- [ ] 专注计时期间切到今日、任务细页或习惯，再返回专注，计时与页面状态继续保留。
- [ ] 番茄钟选"雨声" → 启动 → 扬声器真实播放循环雨声。
- [ ] 暂停 → 500ms 内静音（fadeOut 300ms + tail）。
- [ ] 锁屏并等 30s → 解锁后仍在播放（Android `foregroundServiceType=mediaPlayback`）。
- [ ] 切换到"无白噪音" → 立即停播。
- [ ] 不播放白噪音时开始倒计时/正计时，通知栏折叠态正文第一行是 `剩余 24:53` / `已计时 01:23`，返回桌面后每秒继续走时；暂停冻结并显示“已暂停”，继续恢复、结束/重置清理，到期无负计时。运行态有“暂停/重置”，暂停态有“开始/重置”；开始延续同一任务与剩余，重置回满时长且不增加完成记录。切换主题与语言后文案及强调色同步，“返回专注”进入专注页。切后台 5 分钟后剩余时间与系统时钟一致（主题/语言重推不会延长到期）。

- [ ] 应用锁定、强制更新、切换账号/服务器时面板隐藏，旧面板事件不能操作新账号；解锁后可手动重开，本地未登录模式同样可用。
- [ ] macOS 首次申请通知授权可选择允许或拒绝；通知健康状态与系统设置一致，撤销后刷新显示未授权，重新允许后番茄完成与休息结束的系统通知可送达。
- [ ] 分别记录 Flutter 测试、Swift 面板编译、完整 .app 构建和实机拖动的实际结果；截图放入 evidence/screenshots/macos-pomodoro/，未执行项目保持未勾选。
