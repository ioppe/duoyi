# 手动回归清单（Task 25）

对齐 `.kiro/specs/app-alignment-overhaul/requirements.md`。在可用真机上按顺序走完以下 14 条，出现偏差在"状态"栏打叉 + 补截图到 Issue。

## 1. 启动 & 时区
- [ ] 冷启动后在"我的 → 关于"看到当前 IANA 时区信息（可选；至少日志里 `LocalTimezoneResolver.diagnostics` 为空或只有非致命回退）。
- [ ] 断网启动 → 所有 Tab 可用；App 底部不显示"同步失败"红色状态。

## 2. 推荐目标
- [ ] "目标"页右上 ✨ 按钮 → 打开推荐目标面板。
- [ ] 切换"健康 / 学习 / 运动 / 情感 / 推荐" 5 个分段，每个都有 ≥ 5 条条目。
- [ ] 点击任一推荐条目 → SnackBar "已添加到目标列表"；返回"目标"页能看到新条目。
- [ ] 新条目打开编辑页 → 8 个折叠模块（基础/重复/调度/跳节假日/专注/提醒/时长/次数）都可展开。
- [ ] 今日页所有新建目标入口和目标管理的新建入口均打开底部弹窗，保持背景页面可见，弹窗内不再有独立页面 AppBar。
- [ ] 新建目标与新建任务共用输入字号和尺寸，初始卡片高为可用空间的1/2至2/3、宽度≤720px，浏览展开与顶部下拉收回保留草稿。
- [ ] 目标、笔记、日程、位置提醒、共享空间、自习室、模板及管理员新增表单统一键盘避让、内容滚动、取消、系统返回和遮罩关闭；关闭不创建实体，保存后返回原页面。
- [ ] 页面级创建按钮在桌面与手机均固定在右下角并显示操作文字；习惯页不再在宽屏标题栏放置新建按钮，局部添加操作保持在对应内容区。
- [ ] 目标日期选择、共享空间权限及已有实体的编辑、删除流程仍可正常使用。

## 3. 任务交互
- [ ] 新建一个任务 → 详情页编辑标题 → 点 AppBar ✓ → SnackBar"已保存" + 详情页**不返回**。
- [ ] 继续改标题 → 按系统返回键 → 弹"放弃未保存的修改？" → 点"取消" → 仍在详情页。
- [ ] 再按返回 → 点"放弃" → 回列表，改动未落盘。
- [ ] 任务卡片显示：优先级色点、标签胶囊、下次提醒 HH:MM、目标时长 badge。
- [ ] 勾选完成 → 卡片**保留在今日列表**，显示"已完成"绿色徽章 + 删除线。
- [ ] 取消勾选 → 回到普通态，徽章消失。
- [ ] Web 待办页的今日提醒与筛选位于上方，四象限 / 列表 / 看板页签和任务内容位于下方，宽屏无右侧筛选栏。
- [ ] 自定义视图选中、取消或清空筛选时标题行、筛选区和页签高度与位置一致，快捷筛选与下拉菜单等高；无筛选时清空按钮禁用。

## 4. 子任务 / 顺延
- [ ] 新建任务带 3 个子任务，`autoToggleByChildren = true`（默认）。
- [ ] 依次勾选 3 个子任务 → 父任务自动标为完成。
- [ ] 取消其中一个 → 父任务自动回到未完成。
- [ ] 新建任务设置昨日 dueDate → 下次启动或 resume 时 → `dueDate` 自动顺延到今日同一时刻，`postponeHistory` 增加一条。

## 5. 通知 vs 闹钟
- [ ] 我的 → 通知设置里的「通知健康检查」卡片显示：系统通知权限、精准闹钟权限、通知渠道、测试通知、已调度提醒。
- [ ] HyperOS / MIUI 设备显示自启动、后台与电池、锁屏与横幅、渠道声音四类人工检查项；这些检查项不出现重复的「去设置」按钮，只保留一个疑难设置入口。
- [ ] 从系统设置返回后，卡片状态刷新，提醒详情里的健康提示同步更新。
- [ ] 任务详情页：提醒开关 = ON，kind = **推送**，时间 = 1 分钟后 → 到点系统通知中心出现，不全屏。
- [ ] 切换 kind = **闹钟**，时间 = 1 分钟后 → 到点**全屏 intent 弹出 + 震动**。
- [ ] Android 12+：第一次选闹钟弹"请开启精准闹钟权限"引导（`AlarmPermissionDeniedException` 被捕获时）。

## 6. 专注模式白噪音
- [ ] 桌面侧栏与手机底栏默认显示「今日 / 待办 / 习惯 / 专注 / 我的」，点击专注直接展示计时页并高亮入口。
- [ ] 旧默认导航升级后自动出现专注；自定义导航组合与排序保留，迁移后隐藏专注并重启不会重新添加。
- [ ] 专注计时期间切到待办或习惯，再返回专注，计时与页面状态继续保留。
- [ ] 番茄钟选"雨声" → 启动 → 扬声器真实播放循环雨声。
- [ ] 暂停 → 500ms 内静音（fadeOut 300ms + tail）。
- [ ] 锁屏并等 30s → 解锁后仍在播放（Android `foregroundServiceType=mediaPlayback`）。
- [ ] 切换到"无白噪音" → 立即停播。

- [ ] 全部 / 待完成 / 已达标的计数和列表随打卡、撤回实时更新，正向、反向与弹性习惯保持原有判定。

- [ ] 从热度图中的分组打开习惯详情，编辑、结束与删除仍可用；窄屏与字号放大时无溢出。

- [ ] 四个指标卡与全局卡片风格一致，数字/单位字号紧凑，移动端不出现大字号挤压或明显断层。
