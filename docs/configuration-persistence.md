# 配置、登录会话与部署隔离

## 存储归属

| 内容 | 保存位置 | 重部署/重启 | 退出/切换账号 |
| --- | --- | --- | --- |
| 全站 AI、邮件、注册、备份等管理员设置 | 后端 SQLite `settings` | 保留；默认值只补缺失键，非法负数等无效值按既有规则纠正 | 不受客户端退出影响 |
| 密码/邮箱登录及注册会话 | 后端 SQLite `login_sessions`，只存随机令牌的 SHA-256 | 未过期、未撤销的会话继续有效 | 普通会话退出只撤销请求携带的会话；用个人令牌退出只撤销该个人令牌；安全变更撤销相关凭据 |
| 用户创建的个人访问令牌 | SQLite `access_tokens` | 保留既有有效令牌 | 继续遵循个人令牌的过期与撤销规则 |
| 用户待办、习惯、资料、云端偏好 | SQLite 中用户/工作区对应记录 | 保留 | 客户端缓存按服务器与账号隔离；不能转给下一个账号 |
| 设备日期、时区、导航、提醒等 `pref_*` | 客户端 SharedPreferences；Web 为同 origin 的浏览器存储 | 保留 | 作为设备偏好保留，不等于保留账号业务数据 |
| 当前主题与主题切换计数 | 客户端 `active_brand`、`theme_switch_count` | 保留 | 作为设备外观选择保留；账号解锁/奖励缓存仍清理 |
| 专注同步设备 ID | 客户端 `duoyi_focus_sync_device_id`，仅含随机无凭证标识 | 保留 | 保留，用于本机动作来源；不包含账号和会话历史 |
| 当前共享专注与结算凭证 | 后端账号私有 `focus_runtime`、`focus_commands`、`focus_settlements` | 随 SQLite 保留；客户端恢复后读取权威快照 | 本端退出只断连接、清私有缓存，不自动停止其它设备的会话 |
| 同步基线、通知历史、提醒注册表、WebDAV/OAuth 私密配置 | 客户端账号缓存/私密存储 | 遵循账号与凭据有效性 | 仍清理，避免跨账号泄露或执行旧账号提醒 |
| 已完成的 AI 统计解读与普通 AI 回顾 | 客户端账号私有 `ai_review_history`；统计解读带自然周期/时区和数据截止日 | 同安装保留并恢复，生成中任务只在应用保持运行时跨页面继续 | 仍按私有历史清理，不向下一账号保留；没有新增跨设备同步或通用备份恢复 |

不需要为每次部署创建新配置文件，也不把数据库放进 Web 静态目录。共享偏好与管理员设置的存储不是同一个概念，不能通过保留所有客户端键来解决。

AI 解读的周期分组、保留和异步边界见 [统计 AI 解读归档](ai-report-history.md)。

## 各端配置与覆盖更新

**所有现有客户端都把用户偏好保存在平台用户数据区，与程序包或 Web 发布文件分开。正常覆盖更新应保留配置。** 统一的是保存与清理规则，并不是各平台共用一个配置文件，也不表示设备本地设置已经全部跨设备同步。

| 平台 | 配置保存机制 | 正常覆盖更新的前提 |
| --- | --- | --- |
| Android | 应用私有数据区中的 SharedPreferences；不在 APK 内 | 保持 `applicationId=com.duoyi.duoyi`、兼容签名与原应用数据；覆盖安装，不先卸载或清数据 |
| iOS | 应用身份对应的 UserDefaults；不在应用包内 | 保持 `com.duoyi.duoyi` 身份和合法签名/容器关系；当前有 iOS 脚手架与图标资源，但不在现有 CI 发布目标内 |
| macOS | UserDefaults；当前启用 App Sandbox，配置位于对应用户容器 | 保持 Bundle ID `com.duoyi.duoyi`、沙盒方式和数据目录；替换应用包时保留用户容器。当前 DMG 为未签名构建，不能据此声称已验证所有覆盖安装行为 |
| Linux | 用户应用数据目录中的 `shared_preferences.json` | 保持 `APPLICATION_ID=com.duoyi.duoyi`、当前用户及用户数据目录；依赖库无法取得应用 ID 时会回落到二进制名，因此也保持 `duoyi` 二进制名 |
| Web/PWA | 当前 origin 的浏览器 localStorage，SharedPreferences 使用 `flutter.` 键前缀 | 保持协议、域名和端口；替换服务器静态 release 不清理浏览器数据；同 origin 内仅修改页面路径不等于更换本地存储身份 |

仓库目前没有 Windows runner；不能把传递依赖中存在 Windows 存储插件当作已有 Windows 客户端发布能力。

### 后续开发与发布必须遵守

1. 更新安装包/应用包/静态发布目录，不删除平台用户数据，不以版本号变化为由调用全量清理、重建空偏好或用默认值覆盖已保存值。新增默认值补缺失；已有明确的一次性迁移或无效值纠正要保留条件，不能重置用户自定义值。
   一级导航的兼容纠正仅移除已退出主导航的待办槽位（1）：载入时从 `pref_bottom_nav_order`、`pref_bottom_nav_visible` 过滤该值，将指向待办的 `pref_default_tab` 改为今日（0）并回写。其余有效排序、可见性、隐藏专注、时区、提醒与主题选择保留；不新增存储键，也不清空设备偏好。
2. 保持应用身份、存储键与账号作用域兼容。若必须改变标识、数据目录或键名，需要先有迁移方案；更换 Logo、版本或主题不构成变更身份的理由。
3. 普通账号清理仍按明确的账号键/前缀删除私有数据；`devicePreferenceKeys` 记录设备键归属并用于测试，不是运行时“只有登记才保留”的过滤器。新增设置需明确归属并补相应测试，不能重新引入无差别 `pref_*` 删除。
4. 运行时服务器 URL 和登录状态按现有持久化与服务器/账号绑定处理。更换服务器或账号可以使旧私有缓存/凭据失效，但不能顺带删除设备日期、提醒、导航与主题偏好。
5. 配置保留不等于登录永远有效。每条登录会话的过期、退出撤销和账号安全撤销仍按认证契约处理；后端发布也不会自动更新旧原生安装包。

### 不属于覆盖更新的操作与验证边界

卸载重装、清除应用数据、浏览器清除站点数据、更换系统用户/机器，以及更换应用身份或 Web origin，都可能失去原本的本地存储入口，需要可用的云同步或备份迁移。退出/切换账号会按上述归属清理私有配置，不能承诺所有凭据一并保留。

主动恢复备份可以写入偏好，覆盖恢复还可能删除备份中缺失的键；真正较新的云快照也可以按同步规则更新本机偏好。这些是恢复/同步操作，不能与“安装更新无故重置”混为一谈。

当前已完成共享 Provider/账号清理回归和真实 Web 两次刷新验证，存储身份及更新路径也做了代码审计；这些证据不能替代 Android、iOS、macOS、Linux 的实际覆盖安装验收。发布时按 [手动回归清单](manual-regression-checklist.md) 在可用平台验证，未执行的平台如实标注。

## 登录会话

普通密码/邮箱登录成功后返回的凭据仍是服务端签发的随机令牌，客户端无需长期保存或反复发送密码。会话写入成功提交后才返回客户端；数据库不保存原始令牌。普通会话固定有效期 30 天，重部署不会重置该期限。

同一账号允许多条普通登录会话并存，密码/邮箱登录不再挤掉其它设备。会话摘要按令牌唯一，旧单会话表迁移时保留已有有效记录；每条新会话仍独立遵循原来的 30 天有效期。普通会话退出只撤销请求携带的令牌，不影响该账号的其它登录或个人访问令牌；旧退出请求也不能撤销在它校验后新签发的会话。密码重置、更改密码、禁用、删除和管理员强制重登继续撤销全部相关凭据。验证每次查持久记录，不允许仅凭进程内缓存绕过过期或撤销。多端专注的在线/离线协议见 [同账号多端专注同步](focus-runtime-sync.md)。

升级前只在进程内存中的会话没有可恢复的数据库记录；升级这一次可能需要重新登录。之后签发的会话可跨进程和容器重建保留，不能把旧内存令牌凭空迁移出来。

## 客户端保存与同步

普通退出、无登录状态启动或验证过期会清理私有账号缓存，但不删除设备偏好。清理仍取消旧账号的通知、闹钟和地理围栏，不能因为保留提醒选项就继续执行旧账号任务。

偏好 setter 的完成表示值及相应云同步变更标记已经持久保存。重载会等待在途写入；重载期间的用户修改会自动合流，不要求用户再打开设置页。有效的较旧云时间戳不能覆盖较新的本地偏好，即使进程内待同步标记尚未恢复；真正较新的云设置仍按既有键级规则处理。时间戳使用真实 UTC 瞬时。

## 服务器部署约束

当前实例使用 `/opt/duoyi/data:/data` 挂载，并显式设置 `DUOYI_DB_PATH=/data/duoyi.db`。后端 `.env`、原 `PASSWORD_HASH_SALT`、数据库、上传和备份目录必须保留。构建镜像或重建容器不能覆盖这些路径；不能用空库替换现有库。

发布前做 SQLite 一致性备份，记录旧镜像和 Compose 目标。验证新镜像时应检查管理员设置仍在、登录/同步会话跨真实进程重启有效、撤销后不能复活。只 restart 容器不足以部署新镜像，必须按既有流程 build + recreate。

Web 继续使用同一协议/域名/端口，发布到新 release 目录后只切静态链接。浏览器存储按 origin 隔离；更换域名/IP/协议不会自动迁移旧 origin 的本地设置。此修复不能恢复已被旧版清理、且从未备份或同步过的配置。

## 回归边界

- 真实后端进程重启后，密码登录会话仍可读资料与同步；登出、过期或安全撤销后仍拒绝。
- 数据库只出现会话摘要，管理员 AI/邮件/注册设置与用户同步偏好不被初始化覆盖。
- 客户端仅进程内 SharedPreferences 缓存失效、两次冷启动后，日期、导航、提醒、时区及主题选择保留；这不表示清空应用数据后还能恢复未同步设置。
- 账号私有待办、资料、同步基线、通知历史和集成凭据继续清理。
- 保存与重载交错、立即退出、旧云快照和较新云快照均有定向测试。
