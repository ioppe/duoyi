# 专注与休息安排

专注计时页显示完整的休息安排，并提供独立草稿的设置面板。界面沿用现有默认主题、应用字体、共享内容页签及多端专注云图标；默认布局以已确认的手机/桌面设计稿为依据。

## 页面布局

手机在同一张计时卡片内依次显示阶段标题与完成次数、计时环、横向专注时长选项、可点击的休息摘要、主要计时操作和辅助选项。休息摘要至少显示短休息和长休息分钟数，下一行显示长休息间隔及自动开始状态。开始、暂停/继续与重置、跳过/结束保持现有控制语义与严格模式确认。

宽屏在同一张卡片内使用双栏：左侧计时和主要操作，右侧时长、休息摘要及辅助选项。窄屏退回单栏；内容不足以放入当前高度时滚动，不能通过缩小正文或计时按钮规避溢出。专注和休息阶段保留明确的状态标题，默认主题的休息状态使用语义青绿色。

原生桌面（macOS / Windows / Linux）的时长选择使用分钟下拉框及独立的正向计时开关，完整提供 15 / 25 / 30 / 45 / 60 / 90 分钟，当前自定义时长也保留在选项中。支持鼠标、Tab、方向键和 Enter 操作，运行中、暂停中及跨端只读时禁用；手机与 Web 保留横向选项。页头与计时卡独立，macOS 悬浮窗按钮对齐内容区域右侧边距，计时卡仍居中限宽。

## 配置与默认值

| 配置 | 默认 | 范围 |
| --- | --- | --- |
| 专注 | 25 分钟 | 沿用已有时长选择及存储范围 |
| 短休息 | 5 分钟 | 1–720 整分钟 |
| 长休息 | 15 分钟 | 1–720 整分钟 |
| 长休息间隔 | 每 4 轮 | 1–20 轮 |
| 按 5∶1 联动短休息 | 关闭 | 开 / 关 |
| 自动开始休息 | 关闭 | 开 / 关 |
| 自动开始下一轮专注 | 关闭 | 开 / 关 |

时长在 `PomodoroConfig` 中仍按秒保存。新增 `linkShortBreakToFocus` 缺失时按 `false` 读取，不能以升级为由覆盖已有短休息时长。开启联动后，将专注秒数除以 300 并四舍五入为整分钟，至少 1 分钟，再转换为秒；例如专注 25 分钟对应 5 分钟短休息，60 分钟对应 12 分钟。关闭时保留独立短休息值。长休息不参与比例计算。

## 设置交互

点击整行休息摘要打开共享设置面板。原生 Android / iOS 使用共享底部面板；macOS 与 Web 遵循现有共享居中弹层规则，不增加页面特例。设置包含短休息、联动开关、长休息、长休息间隔及两个自动开始开关。

面板头部和保存区保持可访问，内容可独立滚动，使用共享安全区、键盘避让、焦点与遮罩关闭行为。文字和控件遵守应用字体与字号比例，不截断输入说明，触达区域至少 44。保存前校验整数和范围；无效值留在当前面板说明错误。

编辑使用独立草稿。取消、关闭、遮罩或返回/退出不改配置。保存只合并休息字段，不覆盖打开面板后发生的白噪音、免打扰、严格模式或其他设备设置变化。保存期间阻止重复提交；切换账号/服务器或账号清理后，旧面板不能保存到新身份或显示迟到的成功提示。

进入专注页时，先按当前账号/服务器存储代际加载已有计时配置与恢复数据，再显示可操作的计时和休息设置、执行默认自习室关联。全局延迟启动批次尚未执行时，页面会按需加载，不能以默认的 5/15/4 写回覆盖已有设置。同代际已成功加载后复用当前状态；加载失败显示既有的失败与重试入口，账号代际改变后重新加载。

## 计时与同步边界

保存休息安排不会重置当前运行或暂停阶段的剩余时间、总时长、任务或运行态身份，也不会发送开始、暂停、重置或运行态更新命令。本地计时在下一次阶段切换时读取最新设置；当前多端共享阶段及自动轮转继续以服务端已接收的配置快照为准，之后由客户端重新开始时再携带新设置。

下一次由客户端发出 `start` 时，既有配置载荷携带实际短/长休息秒数、轮次和自动开始值。联动在客户端计算，不新增后端路由、不提升最低后端协议要求，也不将本地设置编辑伪装成当前会话控制。配置仍经现有 `pomodoro_config` 持久化与账号云同步路径传递；运行态与普通配置的边界见 [多端专注协议](focus-runtime-sync.md)。

自由计时保持现有语义，休息摘要标明这是倒计时模式的安排，不新增正计时自动进入休息的行为。预览稿中的设备尺寸、阶段查看工具栏不是产品功能。
